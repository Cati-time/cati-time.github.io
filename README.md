# cati-time.github.io

Cati-time 조직의 GitHub Pages 루트 사이트입니다. 블로그 본체는 [Cati-time/blog](https://github.com/Cati-time/blog) 이고 `https://cati-time.github.io/blog/` 에 있습니다.

이 저장소는 도메인 맨 위(`https://cati-time.github.io/`)만 맡습니다.

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 맨 위 주소를 `/blog/` 로 넘긴다. 네이버 서치어드바이저 소유 확인 태그 자리 |
| `robots.txt` | 모두 허용 + 블로그 사이트맵 위치 |
| `404.html` | 블로그 밖 주소로 들어오면 블로그 링크를 보여 준다 |

블로그 글과 설정은 여기 두지 않습니다.
